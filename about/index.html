About FlatStack

Finding a Hong Kong home should feel less repetitive.

What is FlatStack?

FlatStack is an independent property discovery and search tool for Hong Kong rentals. It brings listing information into one map-and-list view so people can compare relevant homes more easily.

Why we’re building it

Property searches can involve revisiting the same listings and manually comparing details across pages. FlatStack is being built to make that first stage of discovery clearer, faster and easier to manage.

How it works

Listings can be explored on a map or in a results list, filtered by practical criteria such as rent, saleable area, bedrooms and neighbourhood. Available listing details, photos and amenities can be reviewed together, while matching and shortlist tools help narrow the search.

Continue with the original listing

FlatStack helps with discovery; it is not the listing agent or property broker. When a home looks right, the source link takes you to the original listing, where you can confirm the latest details and contact the advertiser or agent directly.
